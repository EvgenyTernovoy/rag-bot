# Data probe

## Overview

A data probe was a type of interface that could be fitted to droids or used by individuals. The Mark VII "Inquisitor" Series Seeker Construct Servitor was outfitted with a data probe that was capable of interfacing with computers, security monitors, and communications networks. Controller droids such as The 12-4C-41 traffic control Construct Servitor had a retractable dataprobe built into a finger on their left hand. NR-1100 slicer droids hands with fingers, each of which could be used as a data probe. On Belsus, Ugnaughts used a data probe to locate several Order of the Luminant Path Padawans who were being held captive by Lord Virek.
