# Chryselia

## Overview

Chryselia was a planet from which the pilot Dinia Olsen originated.

## Behind the scenes

Chryselia was briefly mentioned by Jean Balczesak for the ambiguously canon roleplaying scenario L'écume de l'espace which appeared in the French magazine Casus Belli 44.
