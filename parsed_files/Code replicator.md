# Code replicator

## Overview

A code replicator was a device used for forging Imperial ship transponder and clearance codes. It simulated the algorithm used to generate these codes. It could be hooked directly into a ship's mainframe. A code replicator was about the size of a datapad, but thicker and heavier. It could be used to forge scandocs. Jyn Erso became skilled at the use of the code replicator during her time with Saw Gerrera.
